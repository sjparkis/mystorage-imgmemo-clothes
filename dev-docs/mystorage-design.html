MyStorage

옷 보관 위치 사진/QR/AI 음성 검색 앱

작성일: 2026-11-24 플랫폼: Flutter + Supabase + Anthropic Claude 상태: 설계 완료 (Warm Atelier 디자인 시스템)
목차 개요 기술 스택 아키텍처 데이터 모델 UX Flow 화면 목업 오프라인 AI 통합 AI 음성 검색 결제 플랜 보안 로드맵 제반 사항 배포
Section 01

서비스 개요

옷 보관 위치를 사진과 QR 코드로 관리하고 AI 태그 및 음성으로 검색하는 멀티유저 SaaS

📦

보관함 등록

보관함을 사진으로 찍거나 QR 스티커를 붙여 위치를 디지털화

👕

옷 사진 저장

옷을 찍으면 AI가 색상·종류·계절을 자동 인식해 태그 생성

🔍

빠른 검색

태그나 텍스트로 옷을 찾으면 "3번 박스 2번 칸"처럼 위치 즉시 표시

🎤

AI 음성 검색

"지난 겨울에 샀던 두꺼운 코트" 같은 자연어로 말하면 AI가 의도 파악해 검색

핵심 사용 시나리오

옷 저장할 때

  1. 보관함 앞에서 앱 열기
  2. 보관함 선택 or QR 스캔
  3. 옷 사진 촬영
  4. AI 태그 확인/보완 후 저장

옷 찾을 때 (텍스트)

  1. 앱에서 옷 검색 (예: "파란 니트")
  2. 검색 결과에서 위치 확인
  3. 해당 보관함으로 이동
  4. QR 스캔으로 목록 재확인

옷 찾을 때 (음성)

  1. 마이크 버튼 길게 누르기
  2. "지난 겨울에 샀던 두꺼운 코트" 말하기
  3. AI가 자연어 해석 → 태그 추출 → 검색 실행
  4. 결과에서 위치 확인
Section 02

기술 스택

Flutter + Supabase 올인원 — 별도 백엔드 서버 없이 모든 플랫폼 커버

📱

Flutter (Dart)

iOS · Android · Web(PWA) · Admin Web 단일 코드베이스. 카메라/QR 스캔 네이티브 성능.

프론트엔드 전체
🗄️

Supabase (PostgreSQL)

DB · Auth · Storage · Realtime · Edge Functions. 별도 백엔드 서버 불필요.

백엔드 전체
🤖

Anthropic Claude API

Supabase Edge Functions에서 호출. 모델: claude-haiku-4-5-20251001. 옷 사진 분석 → 이름·태그(7-10개) 자동 생성.

AI 이미지 인식
📴

Drift + SQLite

Flutter 로컬 DB. 오프라인 캐시 역할. 온라인 복귀 시 Supabase와 자동 동기화.

오프라인 지원
📷

image_picker + mobile_scanner

Flutter 카메라 접근 및 QR 코드 스캔 패키지. iOS/Android 모두 지원.

카메라 / QR
🏷️

qr_flutter + printing

QR 코드 생성 및 PDF 스티커 출력. 보관함에 붙일 QR 스티커를 앱에서 바로 인쇄.

QR 생성 / 출력
💳

RevenueCat + Toss Payments

RevenueCat으로 iOS App Store / Google Play 인앱 구독 통합 관리. 웹은 Toss Payments.

결제 / 구독 관리
🎤

speech_to_text (Flutter)

기기 내장 STT 엔진 사용. 음성 → 텍스트 변환. 온디바이스 처리로 추가 비용 없음.

음성 입력 (무료)
💬

Anthropic Claude (자연어 파싱)

변환된 음성 텍스트를 자연어 파싱. 의도 파악 후 태그·필터 추출. 모델: claude-haiku-4-5-20251001.

AI 자연어 파싱

전체 배포 구성

사용자 ├── iOS App (App Store) → Supabase ├── Android App (Google Play) → Supabase ├── Web PWA (Vercel) → Supabase └── Admin Web (Vercel 별도) → Supabase Supabase ├── PostgreSQL (DB + RLS) ├── Auth ├── Storage (이미지 CDN) └── Edge Functions ├── analyze-clothing → Anthropic Claude API ├── parse-voice-query → Anthropic Claude API └── subscription-webhook ← RevenueCat 결제 ├── iOS 구독 → RevenueCat → App Store ├── Android 구독 → RevenueCat → Google Play └── Web 구독 → Toss Payments

핵심 제약사항

Apple 인앱결제 강제 & 외부 결제 유도 금지
iOS 앱 내 디지털 상품은 Apple In-App Purchase 사용 필수. 앱 내에서 외부 결제 유도 문구 금지 (앱 삭제 사유). iOS · Android · Web 모두 동일 가격 표시 원칙.
수수료: App Store 30% (구독 1년 이후 15%) / Google Play 15% / Web(Toss) 2~3%
SQLite 오프라인 캐시는 Web에서 작동 안 함
Flutter Web은 SQLite(Drift)를 기본 지원하지 않음. 오프라인 Drift 레이어는 iOS/Android 전용.
Web PWA는 오프라인 지원 제외 — 서비스 워커로 앱 쉘만 캐시. 웹 오프라인이 필요하면 sqlite3_web(WASM) 별도 도입.
Supabase Free — 7일 비활성 시 프로젝트 자동 정지
1주일간 요청이 없으면 프로젝트 일시정지. 베타 운영 중 서비스가 갑자기 멈출 수 있음.
첫 유료 사용자 발생 즉시 Pro($25/월) 전환 필요. Pro는 자동 정지 없음.
Flutter Web 초기 로딩 — 번들 크기 주의
Flutter Web(CanvasKit) 초기 번들 약 2~5MB. 첫 방문 시 3G 환경에서 5~10초 소요.
PWA 설치 후 재방문은 빠름. HTML 렌더러(--web-renderer html)로 번들 절반 가능하나 렌더링 품질 저하.
Admin Web — 반드시 별도 Vercel 프로젝트로 분리
일반 사용자 앱과 Admin을 같은 빌드에 포함하면 Admin 코드가 클라이언트에 노출됨.
Admin 전용 Flutter 빌드를 별도 Vercel 프로젝트로 배포하고 Supabase Service Role Key + RLS로 접근 제한.
