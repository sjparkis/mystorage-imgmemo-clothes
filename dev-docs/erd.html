03 · 관계 설명

관계 상세 목록

모든 외래 키 참조와 카디널리티, 삭제 동작을 정리합니다.

부모 테이블 자식 테이블 참조 컬럼 카디널리티 ON DELETE 설명
auth.users organizations owner_id 1 : N RESTRICT (기본) 조직 소유자. 사용자가 삭제되면 조직도 삭제 불가
auth.users organization_members user_id 1 : N RESTRICT (기본) 조직 멤버십. 한 사용자가 여러 조직에 소속 가능
auth.users clothes created_by 1 : N SET NULL (nullable) 옷 등록자. 사용자 삭제 시 created_by 가 null 로 변경
auth.users subscriptions user_id 1 : 1 CASCADE 구독 정보. user_id UNIQUE 제약으로 1:1 관계 보장
organizations organization_members org_id 1 : N CASCADE 조직 삭제 시 모든 멤버십 레코드도 함께 삭제
organizations storages org_id 1 : N CASCADE 조직 삭제 시 모든 보관소도 함께 삭제
organizations clothes org_id 1 : N CASCADE 조직 삭제 시 모든 옷 레코드도 함께 삭제
storages clothes storage_id 1 : N SET NULL 보관소 삭제 시 옷은 유지되고 storage_id 만 null 처리
clothes clothes_tags cloth_id N : M CASCADE 옷 삭제 시 해당 옷의 모든 태그 연결도 삭제
tags clothes_tags tag_id N : M CASCADE 태그 삭제 시 해당 태그의 모든 연결도 삭제
UNIQUE 제약
UK storages.qr_code — QR 코드 전역 유일
UK tags.name — 태그명 중복 불가
UK subscriptions.user_id — 사용자당 구독 1건
UK organization_members(org_id, user_id) — 중복 멤버십 방지
UK clothes_tags(cloth_id, tag_id) — 동일 태그 중복 연결 방지
CHECK 제약
organization_members.role
IN ('owner', 'member')
tags.category
IN ('color', 'type', 'season', 'brand', 'custom')
subscriptions.plan
IN ('free', 'ad_free', 'basic', 'ai_voice')
subscriptions.billing_cycle
IN ('monthly', 'yearly')
subscriptions.status
IN ('active', 'cancelled', 'expired')
