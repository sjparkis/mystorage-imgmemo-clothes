organization_members

사용자와 조직 간의 멤버십 테이블. 한 사용자가 여러 조직에 소속될 수 있으며, 역할(role)로 권한을 구분합니다.

M
organization_members
조직-사용자 멤버십. UNIQUE(org_id, user_id) 로 중복 가입 방지
RLS 적용 001_schema.sql
컬럼명 타입 제약조건 설명
id uuid PK DEFAULT gen_random_uuid() 멤버십 고유 식별자
org_id uuid FK NOT NULL → organizations(id) ON DELETE CASCADE 소속 조직 ID
user_id uuid FK NOT NULL → auth.users(id) 멤버 사용자 ID
role text NOT NULL CHECK DEFAULT 'member' 'owner' 또는 'member'. 소유자는 초대/삭제 가능
joined_at timestamptz DEFAULT now() 조직 가입 시각

subscriptions

사용자별 구독 플랜 정보. RevenueCat 과 연동하여 인앱 결제를 관리합니다. 사용자당 1건만 존재합니다 (1:1).

$
subscriptions
구독 플랜 관리. user_id UNIQUE 로 1:1 관계. RevenueCat ID 저장
RLS 적용 003_subscriptions.sql
컬럼명 타입 제약조건 설명
id uuid PK DEFAULT gen_random_uuid() 구독 레코드 고유 식별자
user_id uuid FK NOT NULL UNIQUE → auth.users(id) 구독 사용자. UNIQUE 로 1:1 관계 보장
plan text NOT NULL CHECK DEFAULT 'free' 'free' | 'ad_free' | 'basic' | 'ai_voice'
billing_cycle text CHECK 'monthly' | 'yearly'. free 플랜은 null

expires_at timestamptz 구독 만료 시각. free 는 null (무제한)
revenuecat_id text RevenueCat 구독 ID. 결제 웹훅 연동용
plan 별 기능 범위
free — 광고 포함, 기본 기능 ad_free — 광고 제거 basic — 무제한 보관소 + 고급 필터 ai_voice — AI 태깅 + 음성 검색

INSERT / UPDATE / DELETE 는 서버사이드 RevenueCat 웹훅에서만 처리. 클라이언트 직접 쓰기 차단.

함수 및 뷰

RLS 정책에서 사용하는 헬퍼 함수와 관리자 뷰를 정리합니다.

FUNCTION is_org_member
is_org_member(p_org_id uuid) RETURNS boolean — SECURITY DEFINER
RLS 정책에서 반복 사용되는 멤버십 확인 헬퍼 함수. SECURITY DEFINER 로 실행되어 함수 소유자 권한으로 organization_members 를 직접 조회합니다. 현재 로그인한 사용자(auth.uid())가 대상 조직의 멤버인지 boolean 으로 반환합니다. 
create or replace function is_org_member(p_org_id uuid)
returns boolean language sql security definer as $$
  select exists (
    select 1 from organization_members
    where org_id = p_org_id and user_id = auth.uid()
  );
$$;
사용처
organizations — 4개 정책 organization_members — 2개 정책 storages — 2개 정책 clothes — 2개 정책 clothes_tags — 2개 정책 (간접)
TRIGGER FUNCTION create_default_subscription
트리거: AFTER INSERT ON auth.users — 신규 가입 시 free 플랜 자동 생성
신규 사용자가 가입하면 자동으로 subscriptions 테이블에 plan = 'free' 레코드를 생성합니다. 앱 클라이언트에서 구독 레코드 존재 여부를 체크할 필요가 없어집니다. 
-- 003_subscriptions.sql 에 포함 (구현 예시)
create or replace function create_default_subscription()
returns trigger language plpgsql security definer as $$
begin
  insert into public.subscriptions (user_id, plan, status)
  values (NEW.id, 'free', 'active');
  return NEW;
end;
$$;

create trigger on_auth_user_created
  after insert on auth.users
  for each row execute function create_default_subscription();
VIEW admin_stats
004_admin_view.sql — REVOKE ALL FROM anon, authenticated
전체 서비스 통계를 단일 행으로 집계하는 관리자 전용 뷰. REVOKE ALL ON admin_stats FROM anon, authenticated 으로 클라이언트 접근을 완전 차단합니다. 
create or replace view admin_stats as
select
  (select count(*) from auth.users)        as total_users,
  (select count(*) from organizations)       as total_orgs,
  (select count(*) from storages)            as total_storages,
  (select count(*) from clothes)             as total_clothes,
  (select count(*) from subscriptions
   where plan = 'ad_free'  and status = 'active') as ad_free_count,
  (select count(*) from subscriptions
   where plan = 'basic'    and status = 'active') as basic_count,
  (select count(*) from subscriptions
   where plan = 'ai_voice' and status = 'active') as ai_voice_count;

revoke all on admin_stats from anon, authenticated;
