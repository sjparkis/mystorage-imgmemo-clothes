라우트 구조 개요

GoRouter 기반 선언적 라우팅. /login 외 모든 경로는 세션 인증 필수.

전체 라우트 맵
/login / /storage/add /storage/:id /cloth/add/:storageId /cloth/:id /search /qr-scan /qr-sticker /pricing /admin
인증 리디렉션: GoRouter redirect 훅에서 Supabase auth.currentSession을 검사합니다. 미인증 상태에서 모든 경로 접근 시 /login으로 이동하며, 인증 완료 후 /login 접근 시 /로 이동합니다.

화면 전환 요약

모든 라우트 경로, 진입 조건, 이동 목적지를 정리합니다.

출발 화면 진입 조건 목적지 비고
앱 시작 세션 없음 /login GoRouter redirect
앱 시작 세션 있음 / GoRouter redirect
LoginScreen 로그인 성공 (BLoC) / AuthBloc emit → GoRouter
HomeScreen FAB 탭 /storage/add
HomeScreen 보관함 카드 탭 /storage/:id id = StorageLocation.id
StorageDetailScreen FAB 탭 /cloth/add/:storageId
StorageDetailScreen 옷 카드 탭 /cloth/:id
StorageDetailScreen AppBar QR 아이콘 /qr-sticker extra: StorageLocation 전달
NavigationBar QR 탭 /qr-scan
QrScanScreen QR 스캔 성공 /storage/:id 미등록 QR → SnackBar 오류
NavigationBar 검색 탭 /search
SearchScreen 결과 항목 탭 /cloth/:id
나의 탭 구독 플랜 버튼 /pricing
PricingScreen 시작하기 버튼 RevenueCat SDK OS 네이티브 결제 UI
직접 URL — /admin 별도 인증 미구현
