06 · Platform Guide

반응형 & 플랫폼 가이드

iOS, Android, 웹(PWA) 환경별 주의 사항과 구현 가이드라인을 정리합니다.

플랫폼별 특이사항
iOS
SafeArea: 모든 Scaffold에 SafeArea 적용, 노치/Dynamic Island 대응
카메라 권한: Info.plist — NSCameraUsageDescription
마이크 권한: Info.plist — NSMicrophoneUsageDescription
사진 접근: NSPhotoLibraryUsageDescription
인앱 결제: RevenueCat SDK — StoreKit 2 사용, Sandbox 테스트 필수
폰트: -apple-system (San Francisco) 자동 적용
<!-- Info.plist --> <key>NSCameraUsageDescription</key> <string>옷 사진 촬영</string> <key>NSMicrophoneUsageDescription</key> <string>음성 검색</string>
🤖 Android
Material You: colorScheme.fromSeed로 Dynamic Color 지원
카메라 권한: AndroidManifest — CAMERA
마이크 권한: RECORD_AUDIO
인터넷: INTERNET (Supabase 통신)
인앱 결제: RevenueCat SDK — Google Play Billing
최소 SDK: minSdkVersion 21 (Android 5.0+)
MobileScanner: QR 스캔, Android 카메라2 API
<!-- AndroidManifest.xml --> <uses-permission android:name="android.permission.CAMERA"/> <uses-permission android:name="android.permission.RECORD_AUDIO"/>
🌐 Web (PWA)
kIsWeb 가드: 카메라/마이크/QR 기능 조건부 비활성화
오프라인 캐시: Drift DB 미지원 (database_connection_stub.dart)
RevenueCat: 웹 미지원, PricingScreen 접근 차단 권장
이미지 업로드: image_picker 웹 대응 필요
SafeArea: 브라우저 환경에서 불필요
인앱 결제: Web Stripe 별도 구현 필요
if (!kIsWeb) { // 카메라, QR, 음성 기능 return QrScanScreen(); } else { return WebUnsupportedWidget(); }
